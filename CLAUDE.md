# gluponya.tv

Сайт на GitHub Pages, публикация: коммит и `git push origin main`.

Перед любым изменением, которое добавляет или меняет страницу, язык,
приложение, адрес, заголовок, описание или картинку превью, прочитай
`SEO.md` и пройди его разделы 1–4. Если появилось новое место, которое надо
обновлять, допиши его в `SEO.md`.

В репозитории работают несколько сессий сразу: сначала `git pull --ff-only`,
в коммит добавляй только свои файлы.
